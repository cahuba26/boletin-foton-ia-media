# Medios del Boletín Fotón-IA

Este repositorio guarda **solo las imágenes, los logos y el video** del boletín.
El boletín (textos y diseño) vive en otro repositorio: `boletin-foton-ia`.

Render publica esta carpeta como un sitio estático, por ejemplo:

    https://boletin-foton-ia-media.onrender.com/chip-moneda.jpg

y el boletín carga cada archivo desde esa dirección (ver `public/assets/js/config.js` en el repositorio del boletín).

## Reglas

- Nombres en minúsculas, con guiones y sin tildes: `taller-vigias-1.jpg`.
- JPG de máximo 1600 px en el lado mayor y menos de 400 KB.
- Para reemplazar una foto, súbala con el mismo nombre.
- El inventario completo está en `docs/INVENTARIO_MEDIOS.md` del repositorio del boletín.
